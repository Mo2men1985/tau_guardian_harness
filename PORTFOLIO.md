## Selected work

### 1. Guardian Evidence Gate - AI Code Acceptance Harness

**Public code:** this repository.

An evidence-driven Python harness for testing AI-generated code, collecting structured static-analysis output, performing bounded repair attempts, and producing explicit PASS / ABSTAIN / VETO decisions.

What it demonstrates:

- Python implementation and experiment tooling;
- pytest/JUnit behavioral validation;
- structured Ruff and security-tool integration;
- isolated execution by default;
- exact candidate and evidence hashing;
- bounded repair without self-invented reliability metrics;
- explicit fail-closed decisions when evidence is incomplete.
