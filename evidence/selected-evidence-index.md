# Selected Engineering Evidence Index

## Public code - Guardian Evidence Gate

Repository root: this repository.

Useful entry points:

- `README.md` - evidence model, decision contract, sandboxing, and usage;
- `harness.py` - baseline and bounded repair workflow using direct evidence;
- `ast_security.py` - advisory custom heuristics;
- `docker_sandbox.py` - constrained Docker execution;
- `analyze_results.py` - direct outcome summaries;
- `tests/` - policy, parser, normalization, and task tests;
- `tasks/` / `tg_code/` - internal regression task fixtures;
- `docs/EVIDENCE_SCHEMA.md` - versioned evidence schema.

What this supports:

- hands-on Python development;
- AI coding workflow experimentation;
- automated testing and structured tool evidence;
- fail-closed acceptance logic;
- reproducible evaluation design.

It does not claim that custom heuristics alone prove software security or that the internal task set is an externally validated benchmark.
