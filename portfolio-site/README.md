# Portfolio Site Source

Static one-page portfolio for Moamen Abdelfattah's AI-native engineering work.

- Entry point: `index.html`
- Styles: `styles.css`
- No build step or runtime dependency is required.

It can be deployed as a static site through Vercel, Netlify, GitHub Pages, or any basic web host. The current content links only to public GitHub resources plus LinkedIn/email; private repositories and customer data are not embedded.
